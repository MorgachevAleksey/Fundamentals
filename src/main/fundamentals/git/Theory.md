Команды git:

1) init
2) add
3) commit
    -m
4) push
    - git push origin main
   git push --set-upstream origin dev
5) branch
    - -d - удалить ветку
    - -m <old> <new> - переименоватьь ветку
6) switch - переключить ветку
   - -с - создать и переключить ветку
7) restore
8) reset
9) revert
8) merge
   --no-ff - чтобы был отдельный коммит слияния даже если с мейном не разошлось
После мерджа нужно удалить не главную ветку а то она так и останется висеть мертвым грузом
9) clone
10) pull
11) fetch
12) status
13) log 
    - --graph - отобразить граф коммитов
14) dif
15) stash
16) rebase
17) tag 
    -a


---
Правила оформления коммитов:
- feat: — новый функционал (например, feat: добавлен эндпоинт домашней страницы).
- fix: — исправление бага.
- docs: — изменения в документации (README).
- refactor: — рефакторинг кода без изменения поведения.
- test: — добавление или исправление тестов.
- chore: — рутинные задачи (обновление зависимостей, настройка CI).
