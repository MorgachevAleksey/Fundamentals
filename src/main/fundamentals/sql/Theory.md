Порядок команд (FIXME)

1) SELECT -- перечисление полей результирующей таблицы
2) FROM -- указание источника данных 
3) WHERE -- фильтрация данных ДО группировки
4) GROUP BY -- группировка данных 
5) HAVING -- фильтрация данных ПОСЛЕ группировки 
6) ORDER BY -- сортировка результирующей таблицы 
7) LIMIT -- ограничение количества выводимых записей

---
Команды

- "--" - комментарий
- AS - алиас (можно явно не прописывать (но лучше прописывать))
- SELECT - выбор нужных колонок
    - "*" - выбрать все колонки
- !НЕЛЬЗЯ ПРОВОДИТЬ ОПЕРАЦИИ НАД НОВЫМИ СОЗДАНЫМИ КОЛОНКАМИ НЕ СЛИТНО - ОНИ СОЗДАЮТСЯ ОДНОВРЕМЕННО!
- functions - агрегирующие функции которые можно применять сразу в селекте, можно применять последовательно
  1) SUM - сумма
  2) MIN - минимум
  3) MAX - максимум
  4) LENGTH - длинна
  5) LOWER - приведение к строчным буквам
  6) UPPER - приведение к заглавным буквам
  7) LEFT('строка'\колонка, сколько левых букв оставить) - взять n левых(первых) букв 
  8) SPLIT_PART(колонка, 'разделитель', какую часть вернуть)
  9) CAST(колонка AS нужный тип данных) - приведение, хотя можно и через ::
  10) CONCAT('часть 1', 'часть 2' и т д) - конкатенация строк (автоприведение)
  11) DATE 
  12) DATE_PART(часть, колонка) - возвращает конкретную часть даты
    Части:
    - 'year'
    - 'month'
    - 'day'
    - 'hour'
    - и т д
  13) COALESCE('часть 1', 'часть 2' и т д) - возрат первого слева !не! NULL значения 
  Лайфхак обработки null - указать вторым значением, любое по умолчанию
  14) ROUND(что окргулить, число знаков после точки(по умолчанию целое число))
- FROM - выбор нужной таблицы
- LIMIT n - количетсво отображаемых строчек (желательно ВСЕГДА ограничивать вывод из-за размеров данных)
- ORDER BY - сортировка данных
    - ASC - (по умолчанию) по возрастанию
    - DESC - по убыванию
- CASE 
    WHEN логика THEN вывод
    WHEN ... THEN ...
    ...
    ELSE
    END (сюда можно поставить алиас)
  условная конструкция (логика стандартная (кроме = - оно одно)), можно воспринимать как поле в селекте но кастомное
- WHERE - фильтрация данных
    IN(1,12,144) - кастомный диапазаон (вхождение в массив)
    Сначала выполняется WHERE, потом функции в SELECT, но внутри WHERE можно использовать расчеты\функции
- LIKE - логический оператор поиска шаблона, аля упрощенной регулярки, чувствителен к регистру
    - % - любое количество символов
    - _ - ровно один любой символ
    - NOT LIKE - можно отрицать
  синтаксис '' LIKE ''
- IN - логический оператор проверяющий вхождение в массив - IN (1,12,144)
- BETWEEN - логический оператор проверяющий вхождение в диапазон с включенными границами BETWEEN 5 and 10
    оба можно отрицать
- IS (NOT) NULL - проверка на (не) null

---
Типы данных

- Целые числа
- Числа с плавающей точкой (разделитель точка)
- Строковые (одинарные кавычки)
  - CHAR
  - VARCHAR
  - TEXT
- Дата и время
  - DATE '2000-12-31' (по умолчанию начало суток на '00:00:00')
- Бинарные (двоичные данные)
- Специальные
